# 🎯 角色与任务目标
你是一个顶级的 Python 自动化排版专家。请基于工作区中的 `.ipynb` 代码和 `images/` 中的截图，编写并在本地执行一个 `generate_report.py` 脚本，输出一份排版极其严格的 Word 文档。

# 🚫 绝对禁令
1. **禁止创建虚拟环境**：使用当前终端环境直接运行。
2. **禁止覆盖模板目录**：必须使用 `Document('template/template.docx')` 加载模板，并在生成的末尾另存为到 `output/` 文件夹。

# 🤖 核心工作流 SOP（请严格遵循顺序）

## 步骤 1：智能视觉分析与匹配（脚本编写前的准备）
在你开始编写 Python 脚本之前，请：
1. 读取 `inputs/` 下的 `.ipynb` 文件，理解每个任务/题目的代码逻辑。
2. **调用你的视觉能力**，查看 `images/` 目录下的所有图片内容。
3. 智能分析哪张截图对应哪个代码题目（例如：带有“登录”按钮的截图对应登录界面的代码），一道题目可能对应多张截图，如存在该情况，分析逻辑顺序排列图片顺序。
4. 在即将生成的 Python 脚本中，**硬编码一个字典，将题目序号/代码块与对应的图片真实文件名精准匹配**。

## 步骤 2：生成 `generate_report.py`
编写的脚本必须具备以下严谨的 Word 操作逻辑：

### 1. 封面变量精准替换
遍历文档的 paragraphs 和 tables 中的 runs，将其中的 `{{姓名}}`, `{{学号}}`, `{{学院}}`、`{{专业}}`、`{{时间}}` 等替换为用户输入的内容。替换必须在原有的 `run.text` 上进行，一定要保留下划线等原生格式，一定要保留下划线!确认修改后下划线右端对齐！

### 2. 严格的 Word 标题层级（为更新目录做准备）
请勿使用手动加粗的正文伪装标题！必须使用 `add_heading()` 注入真实的 Word 大纲级别。
*   **一级标题**（例如："实验：编程作业"，该标题居中显示）：
    使用 `heading = document.add_heading('', level=1)`。
*   **二级标题**（例如："题目一"、"题目二" 等）：
    使用 `heading = document.add_heading('', level=2)`。
    
**⚠️ 标题格式覆写规则（极其重要）：**
使用 `add_heading` 后，必须清空其默认格式，并强制应用以下中国高校标准：
- 一级标题要求：四号字 (`Pt(14)`), 微软雅黑, 加粗, 黑色, 段前段后0行, 1.25倍行距。
- 二级标题要求：小四字 (`Pt(12)`), 微软雅黑, 加粗, 黑色, 段前段后0行, 1.25倍行距。
- 字体应用必须同时设置 `run.font.name = '微软雅黑'` 和 `run._element.rPr.rFonts.set(qn('w:eastAsia'), '微软雅黑')`。

### 3. 正文与截图排版
针对每一个题目，按照以下顺序插入内容：
1. 插入二级标题（如上所述）。
2. 插入正文：`"我的作答："` （11号字, 微软雅黑, 1.25倍行距, 段前段后0行）。
3. **代码块**：创建 1行1列的隐藏边框表格，底纹设为 `#F2F2F2`。代码文本使用小五号字 (`Pt(9)`), 微软雅黑, 1.15倍行距, 段前段后0行。
4. 插入正文：`"运行结果："` （同上正文格式）。
5. **插入对应的截图**：根据【步骤1】中你智能推断出的映射字典，读取图片，约束 `width=Inches(5.0)` 并居中对齐。

## 步骤 3：自动执行与修复
写完脚本后，在终端执行 `python generate_report.py`。
如果报 `ModuleNotFoundError`，请使用 `pip install -i https://pypi.tuna.tsinghua.edu.cn/simple` 安装缺失的库并重新运行。
最后将文件保存为 `output/学号_姓名_实验报告.docx`。
